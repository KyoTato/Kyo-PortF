# Kyo Personal Portfolio

A five-page React + Vite portfolio inspired by the editorial motion and dark visual style of Anime.js. Includes an Aurora Borealis aura background, animated Portfolio wordmark, scroll hero, circular project carousel, accordion gallery, and contact form.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run `npm install`
4. Run `npm run dev` and open the local URL printed by Vite.

## Customize

- Edit page content and navigation in `src/App.jsx`.
- Edit colors/layout in `src/styles.css`.
- Replace the sample gallery images and project data in `src/App.jsx`.
- Update `hello@example.com` and the social links in the Contact page.
- The contact form is currently a front-end demo; connect a form service or backend to receive messages.

The supplied component snippets were recreated as local React components so the project runs without importing unavailable files.
